# V3.2.0 — Client Workspace Edition

Built from archived V3.1.2. Local release candidate only.

- Added eleven client-specific modules and shared profile header, compact mobile header, responsive hybrid sidebar/cards, quick actions, breadcrumb, client search/switching, URL fragment routing and browser history handling.
- Main dashboard retained, with clickable client references, upcoming activity and recent client history. Global Notes/Resources, Progress and Forms registers filter the same client records. Calendar retains master and selected-client scopes.
- Separated client training sessions and assessments from the global Help & Training Guide. Added visible additional measurement history and exercise/session history.
- Added multi-file note/form attachment controls on create/edit; saved-resource actions support replacement, download, image preview, sandboxed PDF preview and manual authorized Cloudinary image transfer. Parent deletion retains and unlinks files. Added website resource links and capacity checks, supported extension and basic file signature checks.
- Added dated gallery, filters, before/after comparison, optional archive of prior avatar on replacement, consent view and reconstructed/forward activity history (last 300 newly recorded activities per client).
- Extended schema v1 with optional metadata; no automatic destructive migration. Backend Cloudinary checks committed note/form association and new progress-photo classification. Existing Firebase, vault, reporting, CSV/XLSX, routing and cloud signing infrastructure unchanged.
- Existing source contains a known separate Google reporting Worker redirect incompatibility; no changes in this release. No new environment variables. No live deployment or upload.
